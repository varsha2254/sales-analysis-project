# 📊 Sales Analysis Project

This project analyzes sales data using **Power BI** to understand sales performance, product categories, regions, customers, sales representatives, and sales channels.

### 🛠️ Tools Used

* Power BI
* Power Query
* DAX
  

### 📌 Key Features

* Sales KPI cards
* Sales trends
* Regional analysis
* Product category analysis
* Customer analysis
* Sales representative performance
* Interactive slicers

### 🔄 Workflow

```text
Sales Data → Data Cleaning → Data Analysis → Power BI Dashboard → Insights
```

### 📁 Files

* `sales_data.csv` – Sales dataset
* `sales analysis project.pbix` – Power BI dashboard
